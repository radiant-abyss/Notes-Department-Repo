# Notes Department Bot — NapCat

这一版基于你当前 v4 任务系统继续升级，并兼容旧数据库。**不要删除 `notes_department.db`。**

## 2026-10-30 更新：个人资料、待办与进度

- 新成员先加入工作群，私聊 `注册 姓名`，再发送 `完善信息`。
- 旧成员直接发送 `完善信息`，依次填写学号、主修学院、辅修学院；不会重新注册或丢失任务记录。没有辅修填“无”，未来技术学院填写“未来技术学院-某某学院（或学部）”。途中发送 `取消` 不保存。
- 也可一次填写：`完善信息 0012345678 | 未来技术学院-计算学部 | 无`；用 `我的信息` 核对。
- `我的待办` 汇总资料缺项、进行中及被打回任务，待审核单独列出。
- `更新进度 12 初稿完成，还差例题` 保存本人最近一次进度，不覆盖其他成员、不改变审核状态、不发群公告；正式交付仍用 `提交 12`。
- 管理员用 `信息未齐成员` 查看缺项，用 `任务 12` 查看各参与成员进度。

启动时自动备份并添加新字段，保留原有成员和任务。请保留本机 `config.json`、数据库和凭据；这些运行数据不应提交到 Git。

本地回归测试（只使用临时合成数据库，不连接 QQ 或模型 API）：

```powershell
cd qqBot
python test_profile.py
python test_progress.py
```

## v5 新增

### 1. 提交 → 审核 → 完成
成员不再直接把任务标成完成，而是：

```text
认领 → 提交成果说明/链接 → 待审核 → 管理员通过/打回 → 完成
```

成员命令：

```text
提交 12
完成 12          # 与“提交 12”等价，兼容旧习惯
撤回提交 12
```

发送 `提交 12` 后，Bot 会继续询问成果说明或链接。可以填写：

- GitHub / 网盘链接；
- 群文件名；
- 简单的成果存放位置说明。

管理员审核：

```text
待审核
通过 12 张三
打回 12 张三 第3页公式需要修订
```

多人任务中，每个参与成员分别审核；只有所需人数全部审核通过后，任务整体才变为“已完成”。

### 2. 管理员操作日志

```text
操作日志
操作日志 50
```

记录发布、修改、删除、恢复、重开、审核、管理员/成员调整等操作。

### 3. 统计

```text
本周统计
本月统计
成员统计 张三
```

包括新增任务、整体完成任务、认领份额、审核完成份额、参与人数、当前待审核和进行中任务。

### 4. 自动备份

Bot 启动后会自动创建当天数据库备份，之后每小时检查一次，但每天最多生成一份：

```text
backups/
  notes_department_2026-09-20.db
```

默认仅保留最近 30 份每日备份。

数据库升级到 v5 前还会自动创建一次：

```text
notes_department.backup_before_v5_时间.db
```

### 5. 数据导出

```text
导出数据
```

生成 Excel (`.xlsx`)，包含：成员、任务、认领与提交、管理员操作日志。

```text
导出CSV
```

生成一个 ZIP，里面是多个 UTF-8 BOM CSV 文件。

Bot 会尝试直接通过 NapCat 私聊发送文件；如果当前 NapCat 文件接口发送失败，文件仍会保存在本地 `exports/` 目录，并在私聊中告诉你路径。

### 6. 群公告

为了避免刷屏，只对较重要事件发群公告：

- 新任务发布；
- 任务人数已满；
- 任务信息被管理员修改；
- 任务整体审核完成；
- 任务重开 / 重新开放；
- 任务删除 / 恢复。

普通的提交、审核中的中间步骤仍然主要走私聊。

## 更新方法

1. `Ctrl+C` 停止当前 Bot。
2. 先手动再备份一次你当前的 `notes_department.db`（可选，但推荐）。
3. 用此包中的以下文件覆盖原项目：

```text
bot.py
db.py
requirements.txt
```

4. **保留原来的：**

```text
config.json
notes_department.db
```

5. 激活原虚拟环境后安装新增依赖：

```powershell
pip install -r requirements.txt
```

6. 启动：

```powershell
python bot.py
```

第一次启动会自动迁移旧数据库，旧成员、旧任务、旧认领和旧完成记录都会保留。
